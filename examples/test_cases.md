## 格式说明

### 基本结构

- **一级标题 (#)**：测试套件名称
- **二级标题 (##)**：测试用例分隔符
- **表格**：定义测试用例的元数据字段
- **加粗字段**：定义前置条件、测试步骤、预期结果、测试数据

### 必需字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 测试用例ID | 唯一标识 | TC001 |
| 测试名称 | 用例名称 | 新建采购单 |
| 测试步骤 | 任务指令（自然语言） | 打开应用... |

### 可选字段

| 字段 | 说明 | 默认值 |
|------|------|--------|
| 测试类型 | 类型分类 | 空 |
| 优先级 | P0-P3 | 空 |
| 标签 | 逗号分隔 | [] |
| 设备ID | 目标设备 | 空 |
| 超时时间 | 秒数 | 180 |
| 前置条件 | 执行前条件 | 空 |
| 预期结果 | 验证要点（空格分隔） | [] |
| 测试数据 | 键值对数据 | {} |

### 用例分隔符格式

支持以下格式：
- `## 用例：TC001 - 测试名称`
- `## TC001 - 测试名称`
- `## TC001`

### 预期结果格式

使用空格分隔多个验证点：
- `✅任务完成 ✅操作成功 ✅金额：7元`

### 测试数据格式

使用 `key:value,key2:value2` 格式：
- `类目:苹果, 农户:非伍6, 数量:1`

### 运行方式

```bash
# 单个 MD 文件
python src/api_test_runner.py --csv examples/test_cases.md

# 混合格式（CSV + Excel + MD）
python src/api_test_runner.py --csv test_cases.csv test_cases.md

# 筛选执行
python src/api_test_runner.py --csv examples/test_cases.md --filter-tags smoke
```
